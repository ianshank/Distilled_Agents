# Workflow invariants

- Stages: discover → specify → design → build → evaluate → ship → learn
- Artifact contract: config/workflow-contract.json
- Researcher and critic cannot have run_command or source writes
- Planning Mode + Request Review for this pipeline. Not Always Proceed. Not Fast Mode for multi-file changes
- Browser recordings are product-eval evidence, not a substitute for unit tests
- Human reviews the Walkthrough before merge
