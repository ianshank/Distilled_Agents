# Design: collect-compose-sqe-e2e

Cites: `docs/plans/symbolic-kd/architecture.md` Section 11.4 E2 and Section 12 (E2 note, PR https://github.com/ianshank/Distilled_Agents/pull/35); ADR 0007 (`docs/adr/0007-symbolic-dispose-tools.md`); `openspec/changes/archive/critic-cascade/`; `openspec/changes/sqe-dispose-e2e-bind/`.

## 1. System Overview

```
configs/golden_sets/sqe_hard_ood.jsonl
  -> make collect-sqe-dispose
       scripts/harness/collect_trajectories.py
         --harness-id sqe_dispose
         --scripted tests/fixtures/mock_responses_sqe_passk.json
         --critic / MANGOMAS_CRITIC_ENABLED=1
         --reject-log artifacts/critic_rejects.jsonl
         --output artifacts/trajectories/sqe_dispose_teacher_a.jsonl
  -> (optional second teacher file for DualDistill)
  -> make compose-dualdistill-sqe
       scripts/harness/compose_dualdistill.py
         --first/--second teacher JSONLs
         --reject-log artifacts/critic_rejects.jsonl
         --output artifacts/trajectories/sqe_dispose_dualdistill.jsonl
```

ADR posture: student / teacher proposes; harness H disposes through frozen tool `sqe_constraint_solver` before `final_answer`. E2 connects this dispose-bound trace structure to the trajectory collection and DualDistill composition pipelines with active critic filtering and telemetry.

## 2. Normative Contracts

### 2.1 Makefile Targets

The Implementer SHALL add the following targets with exact names:

1. `collect-sqe-dispose`:
   - Invokes: `scripts/harness/collect_trajectories.py`
   - Harness: `--harness-id sqe_dispose`
   - Inputs: prompts derived from `configs/golden_sets/sqe_hard_ood.jsonl` (or a generated prompt JSONL beside it)
   - Fixture: `--scripted tests/fixtures/mock_responses_sqe_passk.json` for deterministic CI execution
   - Critic: enabled via `--critic` flag or `MANGOMAS_CRITIC_ENABLED=1`
   - Reject sink: `--reject-log artifacts/critic_rejects.jsonl`
   - Output: written under `artifacts/trajectories/` (e.g. `artifacts/trajectories/sqe_dispose_teacher_a.jsonl`)

2. `compose-dualdistill-sqe`:
   - Invokes: `scripts/harness/compose_dualdistill.py`
   - Inputs: two teacher JSONL files generated by dispose collect
   - Reject sink: `--reject-log artifacts/critic_rejects.jsonl`
   - Output: written under `artifacts/trajectories/` (e.g. `artifacts/trajectories/sqe_dispose_dualdistill.jsonl`)

3. Optional alias target `test-critic-sqe-dispose`:
   - Runs pytest markers covering dispose collect and compose critic paths, asserting both required reject codes.

Forbidden:
- Do NOT use target names `collect-sqe` or `compose-dual`.
- Do NOT invent a second Pass@K Makefile target.
- Do NOT route E2 collect through `scripts/harness/run_aqa_gate.py`.

### 2.2 Dispose-Bound Scripted Teacher Fixtures

Teacher rollouts during `make collect-sqe-dispose` MUST execute against `tests/fixtures/mock_responses_sqe_passk.json`:
- For every prompt in `configs/golden_sets/sqe_hard_ood.jsonl`, the recorded trace MUST contain a tool call to `sqe_constraint_solver` prior to calling `final_answer`.
- For in-distribution hard prompts, the tool sequence yields valid DAG/tree observation followed by expected answer.
- For out-of-distribution (OOD) prompts (where `slice == "ood"` OR `ood == true`), the tool sequence yields solver UNSAT/rejection followed by canonical refusal `BLOCKED:<CODE>` per `openspec/changes/_shared/blocked-reject-codes.md`.
- Traces skipping `sqe_constraint_solver` are non-compliant and invalid for student distillation.

### 2.3 Critic Cascade and Rejection Filter

Critic verification is implemented via pure helper functions in `enhanced_system/harness/critic.py`:
- `check_tool_allowlist`: Verifies that executed tools belong strictly to `configs/harnesses/sqe_dispose.yaml` (`sqe_constraint_solver`, `final_answer`).
- `check_expected_tools`: Verifies that `expected_tools` sequence (`[sqe_constraint_solver, final_answer]`) was adhered to.
- `check_outcome`: Evaluates `final_answer` against `expected` using `answers_match`. When `final_answer` does not match `expected`, collect drops the row and logs `critic_reject_code: "OUTCOME_MISMATCH"`.
- `is_recovery_trace`: Ensures trajectories with intermediate faults (`parse_error` or `tool_error`) that ultimately achieve matching `final_answer` are kept in the training set (`critic_kept_recovery`).

### 2.4 Single DualDistill Drop Rule

Compose drops pairs under one and only one rule:
- When **both** teachers fail the grade (score 0), `compose_pair` returns `None` and logs `critic_reject_code: "DUALDISTILL_DROP_0_0"`.
- Strictly forbidden: Any second DualDistill drop rule (such as dropping pairs on partial credit, schema-only faults, single-teacher failures, or heuristic length cutoffs).
- Pairs where at least one teacher succeeds are composed into transition pairs (y1 + transition + y2).

### 2.5 Structured Reject Sink

All reject events from collect and compose are appended as JSONL records to:
- `artifacts/critic_rejects.jsonl` (configurable only via `--reject-log` CLI argument or `MANGOMAS_CRITIC_REJECT_LOG` environment variable).
- Every reject entry contains: `critic_reject_code`, prompt, model/harness identifier, and timestamp.
- The sink MUST record at least one `OUTCOME_MISMATCH` and one `DUALDISTILL_DROP_0_0` entry during test verification.

## 3. Acceptance and Verification Criteria

Milestone E2 is complete when:
1. `make collect-sqe-dispose` executes deterministically on scripted fixtures and writes dispose trajectories with `sqe_constraint_solver` preceding `final_answer`.
2. Unit/integration tests with critic enabled emit `OUTCOME_MISMATCH` to `artifacts/critic_rejects.jsonl` when an intentional answer mismatch is injected.
3. Unit/integration tests emit `DUALDISTILL_DROP_0_0` to `artifacts/critic_rejects.jsonl` when a synthetic (0,0) teacher pair is composed, without dropping under any other rule.
4. `make aqa-gate-passk` remains green with threshold 1.0 on `sqe_hard_ood.jsonl` and is not redefined or altered by E2.
5. Zero references to GKD, Neuroharness, Edge-AI, INV-16, or Serve tool-loop appear in E2 implementation.

## 4. E2E Lifecycle Context (E0-E5)

- **E0:** OpenSpec contract pinning (`openspec/changes/sqe-dispose-e2e-bind/`).
- **E1:** Pass@K x dispose binding landed on `main` (PR #34).
- **E2 (This Change):** Collect -> Critic -> Compose under `sqe_dispose` harness with `OUTCOME_MISMATCH` and `DUALDISTILL_DROP_0_0` reject telemetry.
- **E3:** Behavior cloning (BC) smoke run on `sqe_dispose` harness. GKD enable remains locked until E3 is green.
- **E4:** CI hardening checks for golden rows and fixture solver compliance.
- **E5:** Archive OpenSpec changes upon E2E verification.
